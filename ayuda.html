🧮 Algoritmo de Asignación

🎯 ¿Qué es el Problema de Asignación?

El problema de asignación consiste en asignar recursos limitados a tareas específicas de manera que se optimice una función objetivo (minimizar costos o maximizar beneficios).

👥
Recursos
Personas, máquinas, vehículos o cualquier elemento que necesite asignarse.
📋
Tareas
Actividades, trabajos o proyectos que requieren recursos.
💰
Costos/Beneficios
Valores que representan el costo o beneficio de cada asignación posible.

⚡ Algoritmo Johnson

🔄 Algoritmo Johnson

🎯 Propósito del Algoritmo

El algoritmo Johnson encuentra rutas maximizadas (críticas) y minimizadas (óptimas) en un grafo dirigido acíclico (DAG). Es especialmente útil para análisis de ruta crítica en gestión de proyectos y optimización de redes.

📋 Pasos del Algoritmo

1
Validación del Grafo

Verificar que el grafo cumple con las restricciones del modo Johnson:

  • ❌ Sin bucles (conexiones de un nodo a sí mismo)
  • ❌ Sin aristas bidireccionales entre los mismos nodos
  • ✅ Grafo dirigido acíclico (DAG)
2
Bellman-Ford para Potenciales

Aplicar el algoritmo Bellman-Ford desde un nodo virtual para calcular potenciales (h) que permitan re-ponderar las aristas:

h(v) = min[h(u) + w(u,v)]
3
Re-ponderación de Aristas

Transformar los pesos de las aristas para eliminar valores negativos:

w'(u,v) = w(u,v) + h(u) - h(v)

Nota: Esta transformación preserva las rutas más cortas.

4
Dijkstra desde Cada Nodo

Aplicar el algoritmo de Dijkstra desde cada nodo usando los pesos re-ponderados para encontrar todas las distancias más cortas:

d(u,v) = d'(u,v) - h(u) + h(v)
5
Cálculo de Rutas Críticas y Óptimas

Determinar las rutas maximizadas (críticas) y minimizadas (óptimas) basándose en:

  • 📈 Ruta Maximizada: Secuencia con mayor duración total
  • 📉 Ruta Minimizada: Camino con menor costo total
  • ⚖️ Holguras: Diferencia entre tiempos disponibles

🎨 Guía Visual de Resultados

🔴
Ruta Maximizada
Ruta crítica que determina la duración total del proyecto. Se muestra en rojo con efecto de resplandor.
🟢
Ruta Minimizada
Camino más corto desde el nodo inicial al final. Se muestra en verde con efecto de resplandor.
📊
Métricas ES|LS
Early Start | Late Start por nodo. Muestra los tiempos más temprano y más tarde para cada actividad.
⏱️
Holguras
Diferencia entre LS y ES. Indica el margen de tiempo disponible sin afectar la duración total.

🔀 Algoritmos de Ordenamiento

🫧
Bubble Sort

Complejidad: O(n²)

Compara elementos adyacentes y los intercambia si están en el orden incorrecto.

📥
Insertion Sort

Complejidad: O(n²)

Construye la secuencia ordenada un elemento a la vez.

🐚
Shell Sort

Complejidad: O(n log n)

Una generalización de Insertion Sort que permite el intercambio de elementos lejanos.

🔄
Merge Sort

Complejidad: O(n log n)

Divide el array en mitades, las ordena recursivamente y luego las combina.

✅
Selection Sort

Complejidad: O(n²)

Encuentra el elemento mínimo y lo coloca en la posición correcta.

🚚 Algoritmo NorthWest

🎯 Problemas de Transporte

El algoritmo NorthWest resuelve problemas de transporte donde necesitas minimizar el costo de enviar productos desde múltiples orígenes a múltiples destinos.

📊 Configuración de la Tabla

1
Define orígenes y destinos

Usa los botones "Agregar Fila" y "Agregar Columna" para configurar la dimensión del problema.

2
Ingresa costos

Completa la matriz de costos con los valores de transporte entre cada origen y destino.

3
Define oferta y demanda

Establece la capacidad de cada origen (oferta) y los requerimientos de cada destino (demanda).

4
Selecciona optimización

Elige entre minimizar costos o maximizar beneficios.

🔄 Proceso del Algoritmo

Fase 1: Esquina Noroeste

Encuentra una solución inicial factible comenzando desde la esquina superior izquierda de la tabla y asignando la máxima cantidad posible a cada celda.

Fase 2: Método MODI

Optimiza la solución mediante:

  • Multiplicadores (Uᵢ, Vⱼ): Calculados para celdas básicas
  • Costos reducidos: Indicadores de optimalidad
  • Iteraciones: Mejora progresiva hasta optimalidad
