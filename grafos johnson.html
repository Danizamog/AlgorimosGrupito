⚡ Análisis y Algoritmos

Utiliza estas herramientas para analizar y optimizar tu grafo:

🔄
Maximizar/Minimizar (Johnson)

Propósito: Encuentra rutas maximizadas (rojas) y minimizadas (verdes) en el grafo.

Resultados: Muestra métricas ES|LS en cada nodo
Controles: Panel flotante para mostrar/ocultar rutas
Requisitos: Grafo dirigido acíclico (DAG)
Ruta Maximizada (Crítica)
Ruta Minimizada (Óptima)
🧮
Algoritmo de Asignación

Propósito: Resuelve problemas de asignación optimizando la suma total de pesos.

Maximizar: Encuentra asignación que maximiza la suma total
Minimizar: Encuentra asignación que minimiza la suma total
Basado en: Algoritmo Húngaro para problemas de asignación

📊 Interpretación de Resultados

Métricas de Nodos (ES|LS)

Después de ejecutar el análisis Johnson, cada nodo muestra dos valores:

  • ES (Early Start): Tiempo más temprano en que puede comenzar la actividad
  • LS (Late Start): Tiempo más tardío en que puede comenzar sin retrasar el proyecto

La diferencia entre LS y ES es la holgura del nodo.

Rutas Resaltadas

El análisis identifica y resalta dos tipos de rutas:

  • Ruta Maximizada (Roja): Secuencia de actividades que determina la duración total del proyecto
  • Ruta Minimizada (Verde): Camino más corto desde el inicio hasta el final

💡 Consejos de Uso

🔄 Modo Johnson

  • ✅ Usa nombres descriptivos para los nodos para mejor organización
  • ✅ Planifica la disposición de nodos antes de crear muchas conexiones
  • ✅ Exporta tu trabajo regularmente para evitar pérdida de datos
  • ✅ Utiliza los controles de visualización para analizar rutas específicas
  • ❌ Evita crear bucles o conexiones bidireccionales en este modo

⚡ Análisis

  • Ejecuta el análisis Johnson después de completar tu grafo
  • Usa los controles de ruta para enfocarte en rutas específicas
  • Interpreta las métricas ES|LS para entender las holguras
  • Compara rutas maximizadas y minimizadas para optimización

🎨 Visualización

  • Usa colores contrastantes para nodos y aristas
  • Organiza los nodos de forma lógica y espaciada
  • Aprovecha el grid para alineación precisa
  • Utiliza la matriz para verificar conexiones completas
