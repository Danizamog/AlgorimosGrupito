📊 Interpretación de Resultados

Métricas de Nodos (ES|LS)

Después de ejecutar el análisis Johnson, cada nodo muestra dos valores:

  • ES (Early Start): Tiempo más temprano en que puede comenzar la actividad
  • LS (Late Start): Tiempo más tardío en que puede comenzar sin retrasar el proyecto

La diferencia entre LS y ES es la holgura del nodo.

Rutas Resaltadas

El análisis identifica y resalta dos tipos de rutas:

  • Ruta Maximizada (Roja): Secuencia de actividades que determina la duración total del proyecto
  • Ruta Minimizada (Verde): Camino más corto desde el inicio hasta el final

🚀 ¿Cómo usar el Algoritmo NorthWest?

Sigue estos pasos para resolver tu problema de transporte:

1

Abrir el Algoritmo

En la barra superior, haz clic en "⚡ Análisis" → "🚚 NorthWest (Transporte)"

2

Elegir Tipo de Optimización

Selecciona qué deseas optimizar:

  • Minimizar Costo: Encuentra la solución con el menor costo total
  • Maximizar Beneficio: Encuentra la solución con el mayor beneficio total
3

Ingresar Datos en la Tabla

Completa la tabla con tus datos:

  • Celdas centrales: Costos/beneficios de transportar de origen a destino
  • Columna "Oferta": Cantidad disponible en cada origen
  • Fila "Demanda": Cantidad requerida en cada destino
💡 Tip: Puedes agregar o eliminar filas/columnas con los botones ➕ y ➖
4

Ajustar la Tabla (Opcional)

Usa los botones de control:

  • ➕ Agregar Fila: Añade un nuevo origen
  • ➕ Agregar Columna: Añade un nuevo destino
  • ➖ Eliminar Fila/Columna: Elimina el último origen/destino
  • 🔄 Resetear: Vuelve a la tabla inicial
5

Importar/Exportar (Opcional)

Guarda o carga tus ejercicios:

  • 📂 Importar: Carga datos desde archivo JSON o CSV
  • 💾 Exportar JSON: Guarda el ejercicio completo
  • 📄 Exportar CSV: Guarda solo la tabla de datos
6

Calcular Solución

Haz clic en "🚀 Calcular Solución" y el algoritmo:

  • ✅ Balanceará automáticamente oferta y demanda (si es necesario)
  • ✅ Generará una solución inicial con el método de esquina noroeste
  • ✅ Optimizará la solución usando el método MODI
  • ✅ Mostrará todas las iteraciones paso a paso
7

Interpretar Resultados

Los resultados mostrarán:

  • Costo/Beneficio Óptimo: El valor final alcanzado
  • Iteraciones: Cada paso del proceso de optimización
  • Matriz de Asignación: Cuánto transportar de cada origen a cada destino
  • Multiplicadores Ui y Vj: Valores calculados por el método MODI
  • Costos Reducidos: Mejoras potenciales en cada iteración
💡 Tip: Usa las pestañas "Inicial", "Iter 1", "Iter 2", etc. para ver cada paso

📖 ¿Qué es el Problema de Transporte?

El Problema de Transporte es un modelo de programación lineal que busca encontrar la mejor manera de distribuir productos desde varios orígenes (como fábricas o almacenes) hasta varios destinos (como tiendas o clientes), minimizando costos o maximizando beneficios.

🎯 Objetivo

Determinar cuánto transportar de cada origen a cada destino para satisfacer la demanda al menor costo (o mayor beneficio) posible.

📊 Componentes del Problema

  • Orígenes (m): Puntos de suministro con capacidad limitada (oferta)
  • Destinos (n): Puntos de demanda que requieren productos
  • Costos/Beneficios (cᵢⱼ): Valor asociado al transporte de origen i a destino j
  • Oferta (Sᵢ): Cantidad disponible en cada origen
  • Demanda (Dⱼ): Cantidad requerida en cada destino

🔄 El Método NorthWest (Esquina Noroeste)

Es un algoritmo de dos fases para resolver el problema de transporte:

Fase 1: Solución Inicial - Método de Esquina Noroeste

Genera una solución básica factible inicial siguiendo esta estrategia simple:

  1. Comienza en la celda superior izquierda (esquina noroeste)
  2. Asigna el mínimo entre oferta y demanda disponible
  3. Muévete a la derecha si se agotó la demanda de la columna
  4. Muévete hacia abajo si se agotó la oferta de la fila
  5. Repite hasta asignar todo
📝 Nota: Esta solución inicial NO es óptima, pero es válida y sirve como punto de partida.

Fase 2: Optimización - Método MODI

MODI (Modified Distribution Method) mejora la solución inicial iterativamente:

  1. Calcular multiplicadores (Uᵢ y Vⱼ): Variables duales del problema
  2. Calcular costos reducidos: Para cada celda no básica: cᵢⱼ - (Uᵢ + Vⱼ)
  3. Verificar optimalidad:
    • Minimización: Si todos los costos reducidos ≥ 0 → ÓPTIMO
    • Maximización: Si todos los costos reducidos ≤ 0 → ÓPTIMO
  4. Si no es óptimo:
    • Encontrar celda de entrada (mejor costo reducido)
    • Crear un loop (circuito cerrado)
    • Calcular theta (cantidad a transferir)
    • Aplicar la transferencia y repetir

⚖️ Balanceo del Problema

Para que el problema tenga solución, la oferta total debe igualar la demanda total.

Si no están balanceados, el algoritmo agrega automáticamente:

  • Destino ficticio: Si Oferta > Demanda (con costo 0)
  • Origen ficticio: Si Demanda > Oferta (con costo 0)
⚠️ Importante: Las asignaciones a nodos ficticios representan capacidad no utilizada o demanda no satisfecha.

❓ Preguntas Frecuentes

¿Qué significa "destino ficticio" o "origen ficticio"?

Cuando la oferta total no iguala la demanda total, el algoritmo agrega un nodo ficticio para balancear el problema:

  • Destino ficticio: Si hay más oferta que demanda. Representa capacidad no utilizada.
  • Origen ficticio: Si hay más demanda que oferta. Representa demanda no satisfecha.

Los nodos ficticios tienen costo/beneficio cero y NO afectan el costo/beneficio total.

¿Qué son los multiplicadores Ui y Vj?

Son variables auxiliares del método MODI (también llamadas variables duales). Se calculan a partir de las celdas básicas y sirven para:

  • Evaluar si la solución actual es óptima
  • Calcular los costos reducidos de las celdas no básicas
  • Identificar qué celda debe entrar a la solución básica

¿Qué son los costos reducidos?

Para cada celda NO básica (con asignación = 0), el costo reducido indica:

  • En minimización: Cuánto aumentaría el costo si usáramos esa celda
  • En maximización: Cuánto aumentaría el beneficio si usáramos esa celda

Criterio de optimalidad:

  • Minimización: Todos los costos reducidos ≥ 0 → Solución óptima
  • Maximización: Todos los costos reducidos ≤ 0 → Solución óptima

¿Qué significa "Requiere más iteraciones"?

Esto indica que el algoritmo detectó que la solución NO es óptima (hay costos reducidos que violan la condición de optimalidad), pero no pudo continuar optimizando debido a un problema técnico.

Posibles causas:

  • Problema de degeneración no manejado correctamente
  • No se pudo crear un loop válido para mejorar la solución

Solución: Refresca la página (Ctrl+Shift+R) y vuelve a intentar.

¿Puedo tener costos/beneficios negativos?

Sí, el algoritmo maneja correctamente valores negativos:

  • Costos negativos: Representan ingresos o subsidios
  • Beneficios negativos: Representan pérdidas o costos

¿Cómo interpreto la matriz de asignación final?

Cada celda de la matriz de asignación indica cuántas unidades transportar desde el origen (fila) al destino (columna).

Ejemplo: Si en la celda [Almacén A, Tienda 2] aparece 50, significa: "Transportar 50 unidades desde el Almacén A hasta la Tienda 2"

Las celdas con valor 0 indican que no se usa esa ruta.

¿El algoritmo siempre encuentra la solución óptima?

Sí, cuando el algoritmo converge (termina con "✅ Óptimo"), la solución es matemáticamente óptima y garantizada.

El método MODI es un algoritmo exacto basado en el método simplex de programación lineal.
