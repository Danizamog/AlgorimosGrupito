📘 Ayuda del Editor de Grafos

🎯 Introducción

Este editor de grafos te permite crear, visualizar y analizar grafos dirigidos y no dirigidos. Puedes aplicar algoritmos de optimización como Johnson para encontrar rutas maximizadas y minimizadas.

🖱️ Interacción Básica

Crear y Mover Nodos

  • Clic en el lienzo: Crea un nuevo nodo
  • Arrastrar un nodo: Mueve el nodo a otra posición
  • Doble clic en un nodo: Lo selecciona para crear conexión

Conectar Nodos

  • Doble clic en dos nodos diferentes: Crea una arista entre ellos
  • Menú desplegable "Arista": Selecciona entre dirigida o no dirigida
  • Restricciones:
    • No se permiten bucles (conexiones de un nodo a sí mismo)
    • No se permiten aristas en ambos sentidos entre los mismos nodos

Editar Elementos

  • Doble clic en peso de arista: Edita el valor del peso
  • Clic derecho en nodo/arista: Abre menú contextual con opciones
  • Matriz de adyacencia: Edita todos los pesos visualmente

⚡ Análisis y Algoritmos

Maximizar/Minimizar (Johnson)

  • Propósito: Encuentra rutas maximizadas (rojas) y minimizadas (verdes)
  • Resultados: Muestra métricas ES|LS en cada nodo
  • Controles: Panel flotante para mostrar/ocultar rutas

Algoritmo de Asignación

  • Maximizar: Encuentra asignación que maximiza la suma total
  • Minimizar: Encuentra asignación que minimiza la suma total
  • Basado en: Algoritmo Húngaro para problemas de asignación

💾 Gestión de Archivos

  • Exportar: Guarda el grafo actual como archivo JSON con nombre personalizado
  • Importar: Carga un grafo previamente guardado
  • Los archivos incluyen: Nodos, aristas, colores y análisis guardados

🎨 Personalización

  • Colores de nodos: Personaliza el color de todos los nodos
  • Colores de aristas: Personaliza el color de todas las conexiones
  • Tipos de aristas: Cambia entre dirigidas y no dirigidas

🔧 Funciones Avanzadas

  • Matriz de Adyacencia: Vista completa para edición masiva de pesos
  • Limpieza: Elimina todo el grafo para empezar desde cero
  • Visualización: Grid de fondo para mejor alineación

💡 Consejos de Uso

  • Usa nombres descriptivos para los nodos para mejor organización
  • Planifica la disposición de nodos antes de crear muchas conexiones
  • Exporta tu trabajo regularmente para evitar pérdida de datos
  • Utiliza los controles de visualización para analizar rutas específicas
